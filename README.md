# قالب لندینگ محصول هوش مصنوعی | AI Agent Product Landing Page Template

## فارسی

قالب تک‌فایل HTML برای صفحهٔ معرفی (لندینگ) یک محصول هوش مصنوعی — مثلاً پلتفرم ایجنت‌های هوش مصنوعی، ابزار خودکارسازی یا هر محصول SaaS.

> **نسخهٔ نمایشی (دمو):** فایلی که در این ریپو می‌بینید نسخهٔ دموی قالب است — بخش‌های هیرو، ویژگی‌ها و نحوهٔ کار را نشان می‌دهد تا ببینید به کارتان می‌آید یا نه. نسخهٔ کامل (با جدول قیمت، نقل‌قول مشتری، سوالات متداول و بدون بنر دمو) فقط بعد از پرداخت ارسال می‌شود.

### چه چیزی داخل نسخهٔ کامل است؟

- **هدر چسبان** با منو و دکمهٔ فراخوان (CTA) — در موبایل به منوی همبرگری تبدیل می‌شود
- **بخش هیرو** با تیتر، توضیح، دو دکمه و آمار (تعداد وظایف، ساعت‌های صرفه‌جویی‌شده و…)
- **نوار اعتماد** («Trusted by») با نام شرکت‌ها
- **۶ کارت ویژگی** با آیکون، تیتر و توضیح
- **نحوهٔ کار در ۳ قدم**
- **جدول قیمت‌گذاری** در ۳ سطح، با مشخص‌کردن پلن محبوب
- **نقل‌قول مشتری** و **سوالات متداول** (بازشونده)
- **بخش پایانی CTA** و فوتر با سال خودکار

### چطور شخصی‌سازی کنم؟

همه‌جا که باید چیزی را عوض کنید با `EDIT:` مشخص شده است: نام محصول، رنگ‌ها (متغیرهای CSS در `:root`)، متن هیرو، کارت‌های ویژگی، قیمت‌ها و سوالات متداول. فقط با یک ویرایشگر متن بازش کنید و همان‌جا ویرایش کنید — بدون نیاز به نصب چیزی، بدون بیلد.

### چطور استفاده کنم؟

فایل `index.html` را در مرورگر باز کنید یا روی هر هاست استاتیک (GitHub Pages، Netlify و…) آپلود کنید. فونت Inter از Google Fonts خوانده می‌شود و اگر در دسترس نباشد، فونت سیستمی جایگزین می‌شود.

## English

A single-file HTML landing page template for an AI product — e.g. an AI-agent platform, an automation tool, or any SaaS product.

> **Demo version:** the file in this repo is the demo of the template — it shows the hero, features and how-it-works sections so you can see if it fits your needs. The full version (with the pricing table, testimonial, FAQ and no demo banner) is sent only after payment.

### What's inside the full version

- **Sticky header** with navigation and CTA — collapses to a hamburger menu on mobile
- **Hero section** with headline, subtext, two CTAs and a stats row
- **Social proof strip** ("Trusted by") with company names
- **6 feature cards** with icon, title and description
- **How it works in 3 steps**
- **Pricing table** with 3 tiers and a highlighted popular plan
- **Customer testimonial** and **FAQ** (collapsible)
- **Final CTA section** and footer with automatic year

### How to customize

Everything you need to change is marked with `EDIT:` — product name, colors (CSS variables in `:root`), hero copy, feature cards, prices and FAQ. Open it in any text editor and edit in place. Nothing to install, nothing to build.

### How to use

Open `index.html` in a browser or upload it to any static host (GitHub Pages, Netlify, …). The Inter font loads from Google Fonts and falls back to a system font if unavailable.
